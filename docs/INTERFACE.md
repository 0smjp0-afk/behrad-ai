```

│  🔥 بهراد AI — دستیار هوشمند                │
│                                             │
│  خوش آمدی 👋                                 │
│  مدل فعال: GLM 4.7 Flash ⭐                  │
│  گفتگو: main                                │
└─────────────────────────────────────────────┘
  ┌──────────────┬──────────────┐
  │  🤖 انتخاب مدل │  ⚔️ مقایسه   │
  ├──────────────┼──────────────┤
  │  🧵 گفتگوها   │  🎭 شخصیتها  │
  ├──────────────┼──────────────┤
  │  🧠 حافظه     │  📚 پرامپتها │
  ├──────────────┼──────────────┤
  │  ⏰ یادآورها  │  ✅ تودو      │
  ├──────────────┼──────────────┤
  │  👥 کاربران   │  📊 آمار      │
  ├──────────────┴──────────────┤
  │  ⚙️ تنظیمات  ·  🩺 سلامت     │
```

**جریانِ گفتگو:** هر پیام متنی که بفرستی (بدون اسلش) مستقیم به مدل می‌رود و
پاسخ زنده (حرف‌به‌حرف) می‌آید. اگر لینک بفرستی، صفحه را می‌خواند. اگر عکس
بفرستی، با مدل ویژن تحلیل می‌شود.

## ۶) جریان‌های نمونه

### چت + جستجو
```
تو:   اخبار امروز AI چیه؟
ربات: 🔎 دارم سرچ می‌کنم…
      (با Tavily سرچ و با مدل خلاصه می‌کند)
```

### یادآور از متن آزاد
```
تو:   فردا ساعت ۵ یادم بنداز قبض رو بدم
ربات: ⏰ ثبت شد: فردا 17:00 — قبض رو بدم ✅
```

### عکس‌سازی
```
تو:   /image یک گربهٔ فضانورد روی ماه
ربات: 🎨 دارم می‌سازم… [عکس]
```

### ساخت یادآور با دکمه
```
تو:   ⏰ یادآورها → ➕
ربات: متن و زمان را وارد کن…
```

## English summary

The bot follows a consistent Telegram pattern: a main panel with inline
keyboards, paginated model/persona lists, a settings menu where every row
toggles a setting, and a dashboard/app web UI at `/dashboard` and `/app`. Every
screen exists in Persian (RTL) and English (LTR); each **user** picks their own
language in ⚙️ Settings. The bot streams replies token-by-token, reads links,
analyzes photos, transcribes voice, and runs reminders scheduled from free text
or from the menu.
